**A clean, modern audio studio for macOS.**

Wavforge is a macOS audio application designed to bring music playback, audio organisation and playlist management together in one focused workspace.

Built with simplicity in mind, Wavforge aims to provide an uncluttered environment for working with audio and managing playlists, without unnecessary complexity. Its interface focuses on keeping the listening experience straightforward, organised and easy to navigate.

## Overview

Wavforge is designed around a simple idea: audio software should be powerful in its purpose without feeling overwhelming.

Whether you're listening to music, organising playlists or managing your audio library, Wavforge provides a dedicated space to keep everything together.

## Design Philosophy

Wavforge focuses on three core principles:

- **Simplicity** – A clean interface that keeps the focus on audio.
- **Organisation** – A dedicated space for managing playlists and audio.
- **Usability** – Straightforward controls and navigation designed for macOS.

## Platform

Wavforge is developed for macOS using Apple's Xcode development environment.

## Project

Wavforge is an independent software project focused on creating a streamlined audio experience for Mac users.

The project is continuously being developed and improved, with an emphasis on usability, visual consistency and a polished native macOS experience.

## Development

Wavforge is built as a macOS application. Development and builds are managed through Xcode.
